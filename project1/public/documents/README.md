# Documentation media

The Document page loads these files automatically when present:

- `project1-sketch.pdf`: initial design sketch (already included).
- `demo.mp4`: demo video, played inline with standard controls.
- `presentation.pdf`: presentation PDF, shown inline.
- `example.pdf`: final PDF example section; shows a placeholder until added.

Refresh the Document tab after adding media locally; rebuild and redeploy for the public site.
